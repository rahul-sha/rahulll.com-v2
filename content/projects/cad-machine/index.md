Following one part from a CAD model to CNC-ready code: drawing it, programming the toolpaths, simulating them, and validating the generated NC code.

Many parts can make do with 3-axis machining. For parts like the one shown below, a single 5-axis setup saves time and keeps tight tolerances from drifting between setups.

Where the model has cusps and curved surfaces, the choice of toolpath and ball-nose tool decides how smooth the finish is and which tolerance it can hold.
